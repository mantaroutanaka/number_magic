# 数の魔法（number_magic）

小学1年生向けの、ブロックを「くっつける」「わける」ことで数の仕組みを発見する算数パズルゲームです。

遠山啓の数学教育、とくに具体的な量を操作して数を捉える考え方に着想を得た自主制作作品です。公式教材ではありません。

## 内容
- 12ステージと自由モード
- タップ・ドラッグ、ブロックの分割・結合、ヒント、やり直し
- 進捗の端末内保存、iPad向けPWA

## iPadから遊ぶ
Pagesが有効になれば https://mantaroutanaka.github.io/number_magic/ から遊べます。
Safariの共有メニューから「ホーム画面に追加」できます。

**Pages初期設定**：Settings → Pages → Deploy from a branch → main / (root) → Save。
