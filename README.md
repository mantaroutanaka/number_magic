# 数の魔法（number_magic）

小学1年生を中心に、**具体物の量 → 数唱・数字 → タイル → 5・10の合成**を手で確かめる、探索型の算数ゲームです。

遠山啓の数学教育や水道方式、とくに具体的な量と数を結び付ける考え方から着想を得た**自主制作作品**です。遠山啓の著作・出版社等とは無関係で、公式教材ではありません。

## 学習の流れ（全43ステージ）

| 順番 | 内容 | ステージ |
| --- | --- | --- |
| 導入 | 「どちらがおおい？」で2個と4個を比較 → かさ・ながさ・ひろさを各3問 → 「なかまはどれ？」で仲間外れ探し10問 | 1〜5 |
| 1 | 1〜5で「指定された絵を数える」→「その個数のものを選ぶ」 | 6〜15 |
| 2 | 2つのタイルで5をつくる（1と4、2と3など） | 16〜20 |
| 3 | 6〜10の各数で「絵を数える」→「その個数のものを選ぶ」→「5といくつでその数になる？」 | 21〜35 |
| 4 | 2つのタイルで10をつくる（1と9、2と8など） | 36〜40 |
| 5 | なんばんめかな／いくつとなんばんめ／たて・よこのばしょ（6問・5問・4問） | 41〜43 |

- 数えた絵がアニメーションでタイルの1単位と対応します。
- 数える場面には、正解と同じ個数の別の種類と、近い個数の種類を混ぜます。2〜10の問題ではすべての種類が複数個。1の問題では別の1個の絵と2個ずつの2種類を混ぜ、個数の多い・少ないだけで対象を特定できないようにしています。
- 「その個数のものを選ぶ」課題では、直前とは異なる絵を使い、個数の異なる3種類から選びます。近い数の組み合わせも変え、正解がいつも多さ順の真ん中になることを避けます。「これで たしかめる」で選んだ種類を1個ずつタイルと対応させ、合わなければ同じ配置で選び直せます。
- 種類と配置はステージ開始・「もういちど かぞえる」で変わります。数えている途中や誤タップでは配置を保ちます。
- 数字は「1＝いち、2＝に、3＝さん、4＝よん、…、10＝じゅう」と表示します。読み上げボタンもあります（利用端末の日本語音声機能に依存）。
- 読み上げは音声認識・採点ではありません。「こえに だして よもう」を親子で確認する設計です。
- 3つ以上のタイルを足す課題は設けず、まず**2つだけ**に限定しています。
- 自由モードでは5と10を2つのタイルでつくれます。
- 進み具合はブラウザ内に保存。並び替え前の35ステージ、さらに以前の25ステージのクリア記録を、問題の内容に対応させて引き継ぎます。以後は問題固有のIDで記録するため、問題の位置とクリア記録が混同されません。v2より前の旧ゲームの進捗は引き継ぎません。

## 配信

GitHub Pagesの `main` ブランチ `/(root)` に配置。単純なHTML/CSS/JavaScriptでサーバーや外部APIは不要です。`manifest.webmanifest` と `sw.js` によるPWA・オフライン用キャッシュがあります。初回アクセスおよび新バージョン取得にはインターネット接続が必要です。オフライン動作はブラウザ・端末依存です。

## 検証

Node.jsで `node --test tests/counting.test.cjs` を実行すると、1〜10の各1000配置について正解数・同数の別種類・複数個の種類・IDの重複・配置の変化を確認できます。さらに新しい個数選択課題の各1000通り、課題の並び、旧進捗の引き継ぎも検証します。

## 更新の考え方

数字の暗記や総当たりで突破することを目的にせず、量と表記の対応、5を基準にした数量感覚、10の構成を段階的に扱います。親子で試した観察結果に応じて調整していきます。


## 導入の遊び方

- 「どちらがおおい？」は、回答後に左右の絵を1対1で整列。間違えた場合にも整列を表示し、ペアのない絵を色で示します。
- 「なかまはどれ？」は、6〜9個の絵から、その問の「なかまのきまり」に入らないものを1個選ぶ10問です。きつね・動物・車・果物から始め、動力、現在生存しているか、食事での用途、飛行、水中での生活、楽器の用途へ進みます。
- 分類の基準は毎問明示し、正解後に理由と、別の集合なら同じ仲間になる例を説明します。問題と解説は音声でも聞けます。10問すべてでステージクリアです。ステージ途中の問題番号は保存しません。

- かさ・ながさ・ひろさは各3問。回答後、かさは同じコップ、長さは端をそろえた同じ幅の目盛り、広さは同じ大きさの正方形で確かめます。誤答でも確認図を表示し、同じ問題を選び直せます。かさの図は奥行きが同じ直方体の容器のモデルです。

- 最初のきつねの導入問題を除き、仲間外れ探しの絵はすべて異なる種類を1個ずつ表示します。同じ絵の有無や出現回数だけでは正解を特定できない構成です。

## 順序と位置

10の合成のあとに、順序と位置の3ステージを配置しています。左右・上下・前後のどこから数え始めるかを明示し、個数（集合数）と順番（順序数）を同じ並びで比較します。平面では上／下からの行と左／右からの列を組み合わせ、位置を表します。正解後に数え方と解説を表示。問題と解説は読み上げ可能です。途中の問題番号は保存しません。既存の問題IDとクリア記録は維持します。
