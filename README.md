# 数の魔法（number_magic）

小学1年生を中心に、**具体物の量 → 数唱・数字 → タイル → 5・10の合成**を手で確かめる、探索型の算数ゲームです。

遠山啓の数学教育や水道方式、とくに具体的な量と数を結び付ける考え方から着想を得た**自主制作作品**です。遠山啓の著作・出版社等とは無関係で、公式教材ではありません。

## あそぶ

https://mantaroutanaka.github.io/number_magic/

## 学習の流れ（全35ステージ）

| 順番 | 内容 | ステージ |
| --- | --- | --- |
| 1 | 各数で「指定された絵を数える」→「その個数のものを選ぶ」。1〜10で交互に取り組み、読みとタイルも確かめる | 1〜20 |
| 2 | 2つのタイルで5をつくる（1と4、2と3など） | 21〜25 |
| 3 | 5のタイルにいくつ増えると6〜10になるか調べる | 26〜30 |
| 4 | 2つのタイルで10をつくる（1と9、2と8など） | 31〜35 |

- 数えた絵がアニメーションでタイルの1単位と対応します。
- 数える場面には、正解と同じ個数の別の種類と、近い個数の種類を混ぜます。2〜10の問題ではすべての種類が複数個。1の問題では別の1個の絵と2個ずつの2種類を混ぜ、個数の多い・少ないだけで対象を特定できないようにしています。
- 「その個数のものを選ぶ」課題では、直前とは異なる絵を使い、個数の異なる3種類から選びます。近い数の組み合わせも変え、正解がいつも多さ順の真ん中になることを避けます。「これで たしかめる」で選んだ種類を1個ずつタイルと対応させ、合わなければ同じ配置で選び直せます。
- 種類と配置はステージ開始・「もういちど かぞえる」で変わります。数えている途中や誤タップでは配置を保ちます。
- 数字は「1＝いち、2＝に、3＝さん、4＝よん、…、10＝じゅう」と表示します。読み上げボタンもあります（利用端末の日本語音声機能に依存）。
- 読み上げは音声認識・採点ではありません。「こえに だして よもう」を親子で確認する設計です。
- 3つ以上のタイルを足す課題は設けず、まず**2つだけ**に限定しています。
- 自由モードでは5と10を2つのタイルでつくれます。
- 進み具合はブラウザ内に保存。今回追加した10課題は未クリアとして扱い、それ以前の25ステージのクリア記録は新しい順序に対応させて引き継ぎます。v2より前の旧ゲームの進捗は引き継ぎません。

## 配信

GitHub Pagesの `main` ブランチ `/(root)` に配置。単純なHTML/CSS/JavaScriptでサーバーや外部APIは不要です。`manifest.webmanifest` と `sw.js` によるPWA・オフライン用キャッシュがあります。初回アクセスおよび新バージョン取得にはインターネット接続が必要です。オフライン動作はブラウザ・端末依存です。

## 検証

Node.jsで `node --test tests/counting.test.cjs` を実行すると、1〜10の各1000配置について正解数・同数の別種類・複数個の種類・IDの重複・配置の変化を確認できます。さらに新しい個数選択課題の各1000通り、課題の並び、旧進捗の引き継ぎも検証します。

## 更新の考え方

数字の暗記や総当たりで突破することを目的にせず、量と表記の対応、5を基準にした数量感覚、10の構成を段階的に扱います。親子で試した観察結果に応じて調整していきます。
